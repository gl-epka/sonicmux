# Security policy

## Supported versions

Security fixes target the latest published SonicMux release and the `main`
branch. Pre-release and unsigned-preview artifacts receive best-effort support.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/gl-epka/sonicmux/security/advisories/new)
and include the affected version, operating system, reproduction steps, and
whether untrusted MKV or configuration input is required.

You should receive an acknowledgement within seven days. The maintainers will
coordinate disclosure after a fix or mitigation is available.
